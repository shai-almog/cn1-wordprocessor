# Table formulas and Quick Tables

Table Layout > Formula inserts a calculated, editable field. SUM, AVERAGE, COUNT, MIN, MAX and PRODUCT accept ABOVE, BELOW, LEFT, RIGHT, A1 cell references, rectangular ranges such as A1:B3, and numeric constants. Multiple arguments are comma-separated. Referenced merged cells are counted once within each range; explicitly repeated arguments count again. Deleted text is excluded. Formula keywords are case-insensitive independently of the system language.

Table Layout > Update Formulas and the existing Update Fields action recalculate results after source cells change. Forward dependencies resolve in one pass; dependency cycles produce an explicit `!Circular reference` result. Locked fields keep their cached results. Unknown field functions and unsupported number-format switches retain their cached values. Field updates preserve the active cell, selected cell rectangle and insertion formatting. Insertion and recalculation participate in normal undo/redo. Results are cached fields, not live spreadsheet formulas: editing a source cell does not itself recalculate dependent fields.

The parser treats instructions as data. It bounds instructions to 8,192 characters, arguments to 100, dependency depth to 128 and cell references to the table grid. It accepts `\* MERGEFORMAT`, but not nested functions, arithmetic expressions, bookmarks, IF or `\#` number-format switches. Number parsing currently uses English decimal points, validated grouping and common currency/percent notation. Percent values are read as their displayed number (12% is 12), matching the pinned reference's table parser. Per-cell language properties and comma-decimal locales remain unsupported. Nonintegral results normally show two decimal places; rounding at exact ties and very large-number formatting are not certified equivalent to Wordcraft. Empty MIN/MAX return 0 instead of the reference's extreme floating-point sentinel.

Insert > Quick Tables offers previews of Tabular list, Matrix and Calendar. The native Insert menu exposes the same picker. These are ordinary editable tables with a repeated first header row. Insertion replaces the selected text, retains styled prefix/suffix paragraphs and their comment anchors, and places the caret in the first cell. Cancel makes no document change; the entire insertion has one undo step. Calendar is Wordcraft's reusable 31-day sample, including its final blank row, rather than a calendar calculated from the current date.

The tabular/matrix templates use a blue header, white header text, alternating light-blue rows and a bold first column. Calendar uses a light grid and bold headings. These are materialized character/cell properties. Named table styles, style gallery editing, conditional-style inheritance after structural edits and theme-aware recoloring are not implemented. The paired checks certify contents, dimensions, repeated headers and insertion boundaries, not pixel-equivalent style rendering. Nested quick tables are rejected before changing the document. Text replacement participates in Track Changes, but the inserted table structure itself is not a tracked insertion; tracked structural edits remain a broader gap.

Commands available through the Java SDK, macros, CLI and built-in MCP:

- `table.formula {"formula":"=SUM(ABOVE)"}`; omitted formula defaults to SUM(ABOVE).
- `references.updateFields {}` updates supported formula and reference fields.
- `table.quick {"kind":"tabular"}`; supported kinds are tabular (default), matrix and calendar. Unknown kinds are rejected.

Native storage and DOCX retain formula instructions/results and materialized template contents/appearance. Both readers preserve the tested fields and table content after the other application's export. The paired reference is Wordcraft `159b84f54c74e9e82fb3109b758ae7dd6f4e3ab0`.
